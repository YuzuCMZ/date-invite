# 约会邀请生成器 💌

一个用来约 crush 的小网页。你填好昵称、头像和想一起吃的东西，它给你生成一条链接。对方打开以后会一步一步走完：

1. 「可以和我一起约会嘛？！」，下面有「愿意」和「不要」两个按钮。「不要」每被点一次就换一句话、变小一点、跑到别的地方，「愿意」越变越大。点满 8 次，「不要」就消失了。
2. 「等下，你真的点了愿意？？」
3. 选日期和时间
4. 选吃什么（九宫格）
5. 最后一张汇总卡，对方点「提交给 TA」，结果自动送到你那里。送不出去的时候，页面会退回成「复制结果发给 TA」，让对方复制或截图发你。

文案有两版：**女生发给男生**、**男生发给女生**，语气不一样，生成的时候选一下就行。

## 回信怎么到你手里

生成链接的时候，你会拿到两条链接：

- **邀请链接**：发给对方。
- **看回信链接**：你自己留着，**别发给对方，也别公开发**。

对方走到最后一步点「提交给 TA」，结果（哪天、几点、吃什么）就会送过来。你打开看回信链接就能看到，不用装任何东西。没回信的时候页面显示「还在等 TA 点提交…」，页面开着每 20 秒自己看一次，也可以手动点「刷新一下」。

进阶用法：想让手机直接弹通知，可以装 ntfy App 订阅这个频道。频道名就是看回信链接里 `#reply=` 后面那一串，服务器用默认的 `ntfy.sh`。

这套是靠 [ntfy.sh](https://ntfy.sh) 实现的，它是一个免费的公共推送服务，像一个公共信箱：知道信箱号（频道名）的人能往里投信，也能读信。生成器每次都随机起一个很难猜的频道名。

### 隐私和要注意的

- **回信要经过 ntfy.sh 的服务器**。这个网页自己还是没有服务器、没有数据库，但回信内容会在 ntfy.sh 上过一道。
- **知道频道名的人都能看到回信**，也能往里发消息。频道名就藏在邀请链接和看回信链接里，所以这两条链接都别公开发。
- **ntfy.sh 只把回信留 12 小时**。超过 12 小时才去看，看回信页上就空了。记得 12 小时内用同一台设备打开一次看回信页，看到过的回信会记在这台设备的浏览器里。
- 每点一次「生成」就换一个新频道。旧的看回信链接只收得到旧邀请链接的回信。
- 以前生成的旧链接（没有频道名的）照旧用「复制结果」那一套。

## 它不会做的事

- 你填的东西全部编码在链接 `#` 后面那一段里，打开链接的时候只在对方手机上解出来。
- 除了上面说的 ntfy.sh，不调用别的外部接口，不收集任何数据，不加载外部 JS。

## 头像三种选法

- 选一个内置 emoji
- 上传自己的照片：网页会在你自己的手机上把照片裁成正方形、压成 96×96 左右的小图，直接塞进链接里。照片不会上传到任何地方。
- 填一个图片网址（必须以 `http://` 或 `https://` 开头）

带照片的链接会长一些，大约 3000 字。网页会把整条链接压在 4000 字以内，因为 Telegram 单条消息最多 4096 字。如果某个聊天软件把长链接截断了，就换用 emoji 头像，链接只有一两百字。

## 怎么改文案

所有字都在 `index.html` 里，搜 `可改的文案和数据` 就能找到。用记事本或者任何编辑器打开都能改。

| 想改什么 | 改哪里 |
|---|---|
| 女生版的话 | `COPY.f` 里面 |
| 男生版的话 | `COPY.m` 里面 |
| 点「不要」以后依次出现的话 | `noSteps`（几句都行，点完最后一句按钮就消失） |
| 能选的吃的 | `FOODS`，每行是 `['emoji','名字',默认勾不勾]`，`1` 是默认勾上 |
| 内置头像 | `AVATARS` |
| 时间快捷按钮 | `TIME_CHIPS` |

注意：`FOODS` 用的是**顺序编号**。如果已经发出去过链接，再在中间插入或删除吃的，旧链接里选中的吃的会对不上。新加的东西放到 `其他` 前面就行，发出去的旧链接最好重新生成一遍。

## 一键部署

这个项目只有一个 `index.html`，放到任何能托管静态网页的地方都能用。

### 方法一：GitHub Pages（免费）

1. 在 GitHub 上新建一个仓库，比如叫 `date-invite`，选 Public。
2. 点 **Add file → Upload files**，把 `index.html` 拖进去，点 **Commit changes**。
3. 进仓库的 **Settings → Pages**，**Source** 选 `Deploy from a branch`，**Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶上会出现你的网址，样子是 `https://你的用户名.github.io/date-invite/`。

### 方法二：Vercel（免费）

1. 先按上面第 1、2 步把代码放进 GitHub 仓库。
2. 打开 vercel.com，用 GitHub 账号登录，点 **Add New → Project**，选中这个仓库，点 **Import**。
3. **Framework Preset** 选 `Other`，其他都不用改，点 **Deploy**。
4. 部署完会给你一个 `xxx.vercel.app` 的网址。

### 方法三：Netlify Drop（连 GitHub 都不用）

打开 app.netlify.com/drop，把装着 `index.html` 的文件夹拖进去，马上就能拿到一个网址。

## 用法

1. 打开你部署好的网址（不带 `#` 的那个），这就是生成器。
2. 选「我是女生」或「我是男生」，填昵称、选头像、勾上你想一起吃的东西。
3. 点「生成邀请链接」，然后点「复制链接」发给对方。
4. 点「复制看回信链接」存到自己备忘录里，等 TA 提交以后打开看。
